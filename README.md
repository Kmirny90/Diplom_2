# Diplom_2
# API-тесты Stellar Burgers

## Описание
Автотесты для проверки API приложения Stellar Burgers (космический фастфуд).

## Документация
- [Документация API](https://stellarburgers.education-services.ru/api)
- Базовый URL: `https://stellarburgers.education-services.ru/api`

## Реализованные тесты

### Создание пользователя (`test_create_user.py`)
- Создание уникального пользователя
- Создание пользователя, который уже зарегистрирован
- Создание пользователя без обязательных полей (параметризация)

### Логин пользователя (`test_login_user.py`)
- Успешный логин под существующим пользователем
- Логин с неверным логином
- Логин с неверным паролем
- Логин без обязательных полей (параметризация)

### Создание заказа (`test_create_order.py`)
- С авторизацией
- Без авторизации
- С ингредиентами
- Без ингредиентов
- С неверным хешем ингредиента
